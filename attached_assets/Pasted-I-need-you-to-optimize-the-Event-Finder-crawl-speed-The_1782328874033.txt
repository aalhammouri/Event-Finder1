- Use a simple async semaphore pattern (no external library needed):

  async function processWithConcurrency<T>(
    items: T[],
    concurrency: number,
    fn: (item: T, index: number) => Promise<void>
  ): Promise<void> {
    let nextIndex = 0;
    async function worker() {
      while (nextIndex < items.length) {
        const i = nextIndex++;
        await fn(items[i], i);
      }
    }
    await Promise.all(Array.from({ length: Math.min(concurrency, items.length) }, () => worker()));
  }

  await processWithConcurrency(urls, SITE_CONCURRENCY, async (url, i) => {

  });

=== LEVEL 2: Concurrent page fetching within a site (crawler.ts) ===

Replace the sequential while-loop at line 312 with concurrent page processing.

Implementation:
- Add a PAGE_CONCURRENCY constant = 3 (fetch 3 pages simultaneously per site)
- Change the while-loop to pull PAGE_CONCURRENCY URLs from toVisit at a time
  and process them with Promise.all:

  while (toVisit.length > 0 && visited.size < config.maxPagesPerSite) {
    // Pull up to PAGE_CONCURRENCY URLs from the queue
    const batch: string[] = [];
    while (batch.length < PAGE_CONCURRENCY && toVisit.length > 0) {
      const url = toVisit.shift()!;
      if (visited.has(url) || getDomain(url) !== domain || isStaticAsset(url)) continue;
      visited.add(url);
      batch.push(url);
    }
    if (batch.length === 0) break;

    // Process batch concurrently
    const batchResults = await Promise.all(batch.map(async (url) => {
      // ... existing per-page logic (fetch, keyword gate, extract) ...
      // Return { events, newLinks } for each page
    }));

    // Merge new links into toVisit (event links first, others last)
    for (const result of batchResults) {
      if (result.newLinks) {
        const eventLinks = result.newLinks.filter(isEventUrl);
        const otherLinks = result.newLinks.filter(l => !isEventUrl(l));
        for (const link of eventLinks) if (!visited.has(link)) toVisit.unshift(link);
        for (const link of otherLinks) if (!visited.has(link)) toVisit.push(link);
      }
    }
  }

- IMPORTANT: The visited Set and toVisit array are shared across the concurrent batch.
  Since we pre-pop URLs from the queue and mark them visited BEFORE awaiting, there are
  no races. New links discovered during the batch are added AFTER the batch completes,
  which is correct — they'll be picked up in the next iteration.

=== LEVEL 5: Early termination heuristics (crawler.ts) ===

Add smart short-circuiting to avoid wasting time on sites that clearly have no events:
