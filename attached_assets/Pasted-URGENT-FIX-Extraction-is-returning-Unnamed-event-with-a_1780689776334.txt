FIX 1 — PARSE JSON-LD FIRST (before any AI call)
═══════════════════════════

Many event pages embed structured data in <script type="application/ld+json"> 
tags. This is machine-readable event data — name, date, venue, address, 
ticket prices — that requires ZERO AI to extract.

After fetching any page (whether via Firecrawl or got), BEFORE sending 
to the AI:

1. Search the raw HTML for all <script type="application/ld+json"> blocks
2. Parse each as JSON
3. Look for any object (or nested object in @graph arrays) with 
   "@type": "Event"
4. If found, extract directly:
   - name → eventName
   - startDate → eventDate (parse to ISO)
   - location.name → eventVenue
   - location.address.streetAddress → eventAddress
   - location.address.addressLocality → orgCity
   - location.address.addressRegion → orgState  
   - location.address.postalCode → orgZip
   - description → eventDescription (also scan for "silent auction", 
     "live auction", "raffle", "donate" keywords to set boolean flags)
   - offers[0].price or offers.lowPrice → ticketPrice
   - organizer.name → orgName
   - url → eventPageUrl
   
5. If JSON-LD gives a COMPLETE event (name + date + venue at minimum), 
   SKIP the AI call — use the structured data directly. This is free, 
   instant, and perfectly accurate.

6. Only call the AI if JSON-LD is missing or incomplete.

FIX 2 — CLEAN CONTENT BEFORE AI (when AI IS needed)
═══════════════════════════

When there's no JSON-LD and you need to call the AI, DO NOT send the 
raw markdown from Firecrawl or cheerio. It includes nav menus, footer 
links, breadcrumbs, and sidebar content that confuses the model.

Install @mozilla/readability and jsdom. Before sending to the AI:

1. Load the HTML into jsdom
2. Run new Readability(document).parse()
3. Use the .textContent output (clean main content, no nav/footer)
4. If Readability fails or returns empty, fall back to extracting 
   only the content inside <main>, <article>, or role="main" elements
5. NEVER send raw document.body.innerText or unfiltered markdown
