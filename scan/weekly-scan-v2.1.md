SEND WINDOW AND NEXT-YEAR LOOKUP
- Mail-by date = event date − 21 days (lead_mail_by_date).
- Business days are Monday to Friday. The send window is open when there are at least 10 business days from today up to the mail-by date (roughly 14 calendar days).
- Upcoming event, window open → normal lead (Steps 5–7).
- Upcoming event, window closed (mail-by fewer than 10 business days away, or already past) → do NOT create a lead. Write a Missed Event finding (type 1) with cr93c_reason_detail "Found too late: <n> business days before mail-by <YYYY-MM-DD>; the team needs 10" and schedule the next-year lookup.
- Event already happened (Step 3) → Missed Event finding as before, and schedule the next-year lookup.
- Scheduling the next-year lookup: find the organization's cr93c_scansource row by domain (cr93c_name, or the host of cr93c_website_url); create one if none exists (cr93c_active true, cr93c_scan_priority 1, cr93c_source_list "Missed event follow-up"). Target = (event date + 1 year) − 120 days; if that is earlier than today + 30 days, use today + 30 days. Set cr93c_next_lookup_on = target unless the row already holds an earlier date that is still in the future. Set cr93c_next_lookup_reason = "<event name> (<event date>) — look for the <year + 1> date". Only events that could carry a package qualify: skip the lookup when all four auction fields are a confident No, or the event is a retail format without a Confirmed Yes, or it is Excluded/Sensitive.
- Leads the team misses in the Package Desk (archived with outcome Missed Event) are scheduled by the Desk the same way; Phase B Step 1A picks them up.

SCORING (computed by this run; write the total to lead_event_score and the breakdown to description, one line per signal)
- Auction (max 40): if all four auction fields are No → 0. Otherwise min(40, silent Yes 15 + raffle Yes 12 + live Yes 10 + online Yes 10 + (live Yes and silent Unclear) 8 + prior-year auction Yes 8 + "auction" in event name 5 + "gala" in event name 5).
- Reach (max 30): min(30, complete mailing address 10 + named event contact 5 + contact is Employee 3 + contact title contains director/executive/development/advancement/chief/president/founder 4 + direct e-mail 4 + direct phone 2 + second contact 2).
- Timing (max 15): days until event < 7 → 0; ≤ 20 → 5; ≤ 120 → 15; ≤ 210 → 10; else 5; no date → 0.
- Verification (max 15): min(15, Candid match 6 + address from the organization website 5 + website and Candid addresses agree 4).
- Rating from the total: A ≥ 85, B ≥ 70, C ≥ 55, else D.
- Route (lead_package_status): auction score 0 because all four auction fields are a confident No → no lead (Step 7A). Auction score 0 because the fields are Unclear (Step 4 exhausted) → still a lead, On Hold 714000006 with "Hold", so Phase A revisits it. Auction ≥ 20 and a complete mailing address → Awaiting Review 714000000. Auction ≥ 20 without a mailable address → On Hold 714000006 with "Need address" (or "Email track" when only an e-mail exists) as the first line of description. Auction 10–19 → On Hold with "Research". Auction < 10 → On Hold with "Hold".
- Excluded: "PTA" (case-sensitive), "PTO", "elementary", "preschool" in the organization or event name → Screened Out reason 5. Sensitive: israel, palestin, political, republican, democrat, reproductive, planned parenthood, pro-life, pro-choice → Screened Out reason 6. Neither ever becomes a lead.

Step 3A — Retail and market formats
An event is a retail or market format when its NAME or PAGE DESCRIPTION identifies it as one of: holiday market, Christmas market, winter market, craft fair, craft show, craft market, vendor fair, vendor market, vendor show, bazaar, pop-up shop, pop-up market, pop-up boutique, holiday boutique, holiday gift shop, artisan market, makers market, marketplace, trunk show, farmers market, flea market, rummage sale, garage sale, book sale, plant sale, bake sale, swap meet, shop-small or small-business shopping event. For such an event:
1. No inference may set any auction or raffle field (the venue rules, the golf rule and the prior-year rule are all barred).
2. A Yes is allowed only from Confirmed evidence quoted from that event's OWN page ("silent auction table", "raffle tickets", "bid on", "auction items wanted").
3. No Confirmed Yes → no lead: Screened Out reason 2 with the four auction fields No, quoting the page text (or stating that the page has no auction language) in cr93c_reason_detail.
4. A retail-format event that does carry a Confirmed auction or raffle is processed normally. Kingwood Women's Club "28th Annual Holiday Marketplace" qualifies (confirmed silent auction and raffle).
5. Judge the format, not the word: "Empty Bowls presented by the Bulldog Marketplace" is a charity luncheon, not a retail format.

Step 5A — Venue, then silent-auction inference
Set lead_venue from the event name AND the page description: black-tie or attire language, "seated dinner", "cocktail hour", "table sponsor" → Gala; "shotgun start", "tee time", "foursome", "scramble" → Golf Tournament; "seated lunch", midday start → Luncheon. Other only when the format genuinely is none of these (walk/run, poker night, pickleball, clay shoot, casino night).
Silent-auction inference applies only where lead_silent_auction would otherwise be blank or Unclear, never where Step 3A bars inference, and never over a Yes/No confirmed from page text:
- Gala → Yes. Dinner → Yes (treat as Gala).
- Golf Tournament → Yes (owner rule 2026-10-16: about 90% of charity golf tournaments run a silent auction), with lead_auction_evidence = Assumed and snippet "Assumed: golf tournament (GCP rule: ~90% include a silent auction)". Not when the event's own page says there is no auction. Golf only, not clay shoots or sporting clays.
- Luncheon → Yes only with some indication of a live auction, raffle or request for in-kind donations.
- Festival, Breakfast, Art Event, Other → no venue inference; prior-year rule only.
Prior-year rule: a matching prior instance of THIS SAME EVENT (organization AND normalised event name, up to 3 years back) that confirmed a silent auction may set lead_silent_auction = Yes. It may never set Online, Live or Raffle. A different event of the same organization does not count.
Set lead_prior_year_auction (Yes / No / Not checked) on every lead; never blank.
lead_auction_evidence is never blank: Confirmed (quote stored in lead_auction_evidence_snippet), Assumed (the snippet MUST name the rule that fired; an Assumed Yes with a blank snippet is invalid → set the field Unclear and the evidence Unverified), Unverified (a value with no quote or rule behind it, including budget exhaustion). Never stamp Confirmed on something you did not read.
